## Principles

- **Evidence, not opinions.** Every number shown comes from HORI or from a named NASA service.
- **Honest uncertainty.** "Not knowable yet" is a valid answer, with how long it would take to know.
- **Labels never lie.** Real, estimated, simulated and example values are always marked.
- **No advice, no alarms, no forecasts.**
- **Light and open.** It runs on a modest laptop and on a static website.
